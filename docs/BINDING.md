# vJoy ↔ 功能对应表

> 绑键时对着这张表填。**代码里编号从 0 数，DCS 里显示从 1 数，差一位** —— 这是最容易绑错的地方。

---

## 一、轴（6 个）

| vJoy 轴 | 功能 | 手机操作 | DCS 里绑到 | 灵敏度建议 |
|---|---|---|---|---|
| **X** | 左右 / 滚转 | 手机横滚 | Roll | 曲线 15–25 |
| **Y** | 前后 / 俯仰 | 手机俯仰 | Pitch | 曲线 15–25（已默认反转） |
| **Z** | 油门 | 左侧竖条滑动 | Throttle | 线性 |
| **Rz** | 脚舵 | 底部滑块 或 拧手机 | Rudder | 曲线 10–20 |
| **Rx** | 视角横 | 右侧视角区横向拖 | 相机水平（Absolute） | 线性 |
| **Ry** | 视角纵 | 右侧视角区纵向拖 | 相机垂直（Absolute） | 线性 |

**视角轴必须绑「Absolute」，不是「Axis」** —— 绑错会变成「按一下动一点、松手不回」，拖到哪停到哪的感觉就没了。

**轴反了怎么办**：DCS 里在绑定的轴上点 `Invert`，或者在启动器加 `--negate y` 之类。别改手机端，那是全局的。

## 二、按钮（12 个，其中 3 个是预留）

> **2026-11-13 核查更正**：下表「DCS 里搜」这一列原来写的是跨机型通用关键词
> （`Trigger` / `Pickle` / `Weapon`…）。**JF-17 里这些名字根本不存在** —— 它用自己
> 的 HOTAS 命令名（`S3:` / `S4:` / `S8:` / `T2_Backward:` / `T5_Press:`），
> 在操控界面搜 `Weapon Release` 会一无所获。已按安装目录里的
> `Mods/aircraft/JF-17/Input/JF-17/joystick/default.lua` 与
> `Cockpit/Scripts/command_defs.lua` 改成实际名字。换别的机型时仍按该机型自己的命令名找。

| vJoy | 代码常量 | 功能 | 手机位置 | DCS 里搜（JF-17 实际名） | 命令类型 | 状态 |
|---|---|---|---|---|---|---|
| **BTN1** | `FLAPS_UP = 0` | 襟翼收起 | 起降页 · 底部左一 | `Flaps` | 按下型 | 已有 |
| **BTN2** | `FLAPS_DOWN = 1` | 襟翼放下 | 起降页 · 底部左二 | `Flaps` | 按下型 | 已有 |
| **BTN3** | `GEAR = 2` | 起落架收放 | 起降页 · 底部最右 | `Gear` | 按下型 | 已有 |
| **BTN4** | `WEAPON_PREV = 3` | 循环选武器 | 战斗页 · 武器↑ | `S8: Change Weapons` | **脉冲** | 已有 |
| **BTN5** | `WEAPON_NEXT = 4` | 循环选武器 | 战斗页 · 武器↓ | `S8: Change Weapons` | **脉冲** | 已有 |
| **BTN6** | `LOCK = 5` | 雷达锁定 | 战斗页 · 锁定 | `T5_Press: Lock Target` | **保持** | 已有 |
| **BTN7** | `FIRE = 6` | **武器投放** | 战斗页 · **右上角**发射组 · 右（红） | `S3: Weapon Launch` | **保持** | 已有（语义改了，见下） |
| BTN8 | `RESERVED_TWS = 7` | 格斗模式 | — | `S1_Forward: DGFT - Dogfight Mode` | 脉冲 | **预留** |
| BTN9 | `RESERVED_TARGET_PREV = 8` | 退出格斗 / 解锁目标 | — | `S1_Press` / `S2_Press: Unlock Target` | 脉冲 | **预留** |
| BTN10 | `RESERVED_TARGET_NEXT = 9` | 格斗子模式 | — | `S2_Forward / Backward / Right`（BS / VERT / HA） | 脉冲 | **预留** |
| **BTN11** | `COUNTERMEASURE = 10` | 干扰弹投放 | 战斗页 · 干扰弹（琥珀） | `T2_Backward: Countermeasures Dispense` | **脉冲** | 已有 |
| **BTN12** | `GUN_FIRE = 11` | **机炮** | 战斗页 · **右上角**发射组 · 左（红） | `S4: Fire Main Gun` | **保持** | **新增 2026-11-13** |

**「命令类型」决定手机端该怎么按**：

- **保持型**（`down` + `up`，`value_down = 1.0` / `value_up = 0.0`）：DCS 读的是按钮**状态**，
  按住 = 1 才持续生效，松手 = 0 停止。机炮连射、导弹发射、T5 锁定都是这一类。
- **脉冲型**（只有 `down` 或 `pressed`）：按一下触发一次，按住不放**不会**重复。
  切武器、投放干扰弹、进/出格斗模式、切子模式都是这一类。
- vJoy 按钮本来就是「按下=1 / 松开=0」的状态型，**两类都能带**，不用做任何转换。

**JF-17 没有「上一个 / 下一个武器」两条命令**，只有 `S8: Change Weapons` 单向循环。
所以手机上的「武器 ↑」「武器 ↓」目前只能绑同一条命令（两键都循环），
或者一个绑 `S8`、另一个绑 `S5: Change/Unselect Weapon Station`（语义是切挂点，不是上/下）。
别指望它们像菜单一样上下翻。

预留的三个**现在别绑**，等加了功能再绑 —— 先绑了会占着键位，之后改起来又要重记。

### ⚠️ 机炮和武器投放是两个键（2026-11-13 改）

JF-17 里 `S4: Fire Main Gun`（机炮扳机）和 `S3: Weapon Launch`（导弹发射 / 投放）
是**两条互相独立**的命令，都在 `HOTAS` 分类下。旧版一个 `BTN7` 把两者混绑，
结果一个按钮只能绑一条：要么打不出机炮，要么一扣扳机就把挂架上的东西丢出去。

编号**不重排**（一重排，各机型已经绑好的键全废），代价是要做一次迁移：

| 步骤 | 做什么 |
|---|---|
| 1 | 确认 vJoy 按钮数 ≥ 12（见 §3），**重启 DCS** |
| 2 | 各机型里找到原来绑在 `JOY_BTN7` 的那条命令：如果绑的是 `S4`（机炮），把它**改绑到 `JOY_BTN12`** |
| 3 | `JOY_BTN7` 重新绑到 `S3: Weapon Launch` |
| 4 | 顺便清掉 vJoy 上 `JOY_BTN1 / BTN2` 的默认绑定（见下），再进任务各试一次 |

> 换机型时命令名会变（别的机型可能叫 `Cannon`、`Weapon Fire`、`Pickle`、`Store Release`），
> 在操控页搜语义对应的那条，别只按字符串死记。**JF-17 就是上面的 S3 / S4。**

### ⚠️ 默认绑定冲突：`JOY_BTN1` / `JOY_BTN2`

`joystick/default.lua` 里 S3 / S4 自带默认绑定：

```lua
{combos = {{key = 'JOY_BTN2'}}, down = key_cmds.HOTAS_Stick_S3,
 value_down = 1.0, up = key_cmds.HOTAS_Stick_S3, value_up = 0.0, name = _('S3: Weapon Launch')}
{combos = {{key = 'JOY_BTN1'}}, down = key_cmds.HOTAS_Stick_S4,
 value_down = 1.0, up = key_cmds.HOTAS_Stick_S4, value_up = 0.0, name = _('S4: Fire Main Gun')}
```

vJoy 作为**新设备**接入时，DCS 会把这套默认绑定也套上去。而手机的 BTN1 / BTN2 是
襟翼收 / 放 —— DCS 允许一个物理按钮同时挂在多条命令上，于是**点襟翼可能顺带开炮 / 发射导弹**。

绑之前先在操控页搜 `S3: Weapon Launch` 和 `S4: Fire Main Gun`，把 **vJoy 那一列**的
`JOY_BTN2` / `JOY_BTN1` 默认绑定删掉（保留你要的 BTN7 / BTN12），再点 OK 保存。

### 机炮按钮按下去之前，飞机还得先满足两个条件

中文手册 4.3.1：**先选中 GUN**（HOTAS `S1_Forward` 前推两次，或在 SMS 页点 `GUN`），
**首次使用 / 卡弹后还要点 `FEED` 充弹**（火药弹只有 3 发，点超过 3 次不再响应）。
这两个入口目前都不在手机战斗页上，得去 iPad 的 SMS / MFD 页点。`S4` 绑得再对，
没选 GUN 或没充弹就是抠不动扳机 —— 别误判成手机没发按钮。

## 三、绑之前必须做的两件事

1. **vJoy 的按钮数要 ≥ 12**（代码上限 `MAX_BTN = 30`，够了）。新增的机炮在 `BTN12`，只有 11 个按钮的话它在 DCS 里根本不会出现
2. **改完 vJoy 配置必须重启 DCS** —— 它只在启动时枚举设备。不重启的话，改之前配的按钮数一直有效，新按钮在绑定界面里根本不出现，你会以为是我代码没生效

---

## 四、按机型绑，各存一份

DCS 的输入配置是**每机型独立**的。同一套 vJoy 按钮，在 JF-17 里绑一次、在 F/A-18 里再绑一次，各存各的，互不影响。

所以切机型不用改 App，也不用重装 —— 只需要在 DCS 里重绑一次（每个机型只做一次）。

## 五、长按时长（不是 bug，是防误触）

| 按钮 | 按住多久才生效 | 为什么 |
|---|---|---|
| 武器切换 / 锁定 / 干扰弹 | **150ms** | 滤掉手指划过。触摸屏没有物理边界，划过去在系统看来就是一次点击 |
| 机炮（BTN12）/ 武器投放（BTN7） | **250ms** | 更贵一点：划过就开火等于误碰打出一枚导弹 / 一梭子机炮 |
| 襟翼 / 起落架 | 立即 | 它们是「按住持续动作」，DCS 那边本来就是按住才动 |

按住时按钮边框会变亮、底部有条进度填满，**填满才算数**。

## 六、在 DCS 里绑键的完整步骤

1. **确认手机和电脑连上了**：跑 `tools\start-usb.bat`，看到 `[3/3] 服务启动` 再往下做
2. 打开 DCS → 主菜单 → **设置 / Options** → **操控 / Controls**
3. 左上角的下拉框选 **JF-17**（这一步最容易漏，绑成别的机型会发现「明明绑了却没反应」）
4. 在搜索框里输入 §2 表里的关键词（比如 `Flaps`）
5. 找到对应命令，点它右边那一格 → **按一下手机上的按钮** → DCS 会自动认出 `JOY_BTNx`
6. **点「确定 / OK」保存**。DCS 不会自动存，点右上角 X 关掉就白绑了
7. 绑完建议：右下角 **Save Profile As**，存成比如 `fengzijie-jf17.diff.lua`。以后重装游戏、换电脑都能一键恢复

**绑轴和绑按钮不是同一个入口**：轴在上面的 **Axis Assign** 标签页，按钮在 **All/Keyboard** 那一栏往下翻，别在轴的页面里找襟翼。

## 七、绑完不生效，按这个顺序查

| 现象 | 先看什么 |
|---|---|
| 按手机按钮，DCS 绑定界面里**根本不出现 `JOY_BTNx`** | vJoy 没通。跑 `python tools\vjoy_out.py --report`，看按钮数是不是 ≥ 12（机炮要 BTN12）；再看 DCS 有没有重启过 |
| **只有机炮键没反应** | 多半是 vJoy 还只有 11 个按钮，或 §2 的迁移没做（`JOY_BTN12` 没绑到 `Gun/Trigger`） |
| 绑定界面能认出按钮，但**飞机没反应** | 绑错命令了。同一功能在 DCS 里常常有好几条（比如起落架有 `Toggle` / `Up` / `Down` 三条），换成另一条试 |
| **轴**能绑但飞机不响应 | 绑到了键盘栏的轴，不是 `Axis Assign` 里的。回到轴页面重绑 |
| 轴方向反了（前后颠倒） | 在 `Axis Assign` 里该轴上点 **Invert**，不要改手机端 |
| 视角拖到哪停不到哪 | 视角轴绑成了 `Axis` 而不是 **`Absolute`** |
| 按钮位置对了，但要按很久才有反应 | 这是设计（见 §5）。如果觉得发射的 250ms 太长，告诉我改 |

## 八、换机型时

不用改 App、不用重装。**每个机型在 DCS 里各绑一套**，互不影响 —— 切飞机时用 DCS 左上角的下拉框换配置即可。

唯一要做的是：新机型进去照 §6 再走一遍。**先只绑「机炮」和「武器投放」两个**，飞一次确认两个发射键互不串，再补「锁定」和其他 —— 一次绑四个，出问题分不清是哪个。

## 九、能不能用这套按键逻辑打空战（2026-11-13 评估）

**结论：链路和按钮状态机本身支持；但按现在的按钮集合 + 250ms 门槛，
只够「把弹打出去」，不够「打一场」**，尤其视距内格斗（ACM / DGFT）。

查证来源：DCS 安装目录 `Mods/aircraft/JF-17/Input/JF-17/joystick/default.lua`（命令语义
与默认绑定）、`Cockpit/Scripts/command_defs.lua` 的 `cmd_names`（操控界面显示名）、
JF-17 中文手册 4.3.1 / 4.3.2、以及项目里的 `YokeController.kt`、
`Controls.kt::GuardButton`、`tools/vjoy_out.py`。

### 9.1 状态机这一层：支持

| 能力 | 依据 | 判定 |
|---|---|---|
| **保持型**命令（S4 机炮 / S3 投放 / T5 锁定）按住才持续生效 | `pressButton()` 置 `btnHeld` 位，`releaseButton()` 才清；`vjoy_out.py` 用 `dev.button(i, bool)` 写**状态**而非脉冲 | ✅ |
| **脉冲型**命令（S8 切武器 / T2 干扰弹 / S1、S2 模式键）按一下触发一次 | 一次 down→up 即一次脉冲；`MIN_PULSE_MS = 120ms` 兜住 DCS 每帧采样，快速点按不会丢 | ✅ |
| 多键同时按 | `buttons` 是 30 位位图；每个 `GuardButton` 各自 `pointerInput`，Android 多点触控独立 | ✅ |
| 松手 / 断链立刻停火 | `releaseButton` 清位；50Hz 看门狗 500ms 无消息释放全部按钮；`stop()` 先发全 0 再停 | ✅ |
| 不重复发射 | vJoy 状态型，`want != btn_state` 才写驱动 | ✅ |

### 9.2 支撑不住对抗的四个缺口

| # | 缺口 | 后果 | 证据 |
|---|---|---|---|
| 1 | **发射键 250ms 长按门槛** | 开火延迟 250ms，短点射（<250ms）被整个吞掉；狗斗瞄准窗口常只有 0.2–0.5s | `GuardButton` 的 `withTimeoutOrNull(guardMs)` 到点才 `onDown()` |
| 2 | **没有 ACM / 格斗模式、目标解锁、子模式、主模式切换** | 视距内 10NM 自动截获进不去，雷达锁不上就没法近战 | 手册 4.3.2：`S1_Forward` 进 DGFT、`S2` 切 BS/VERT/HA；代码里 7–9 号仍是 `RESERVED_*` 空位 |
| 3 | **没有机炮选择 / FEED 充弹入口** | S4 绑对了也可能抠不动扳机 | 手册 4.3.1；见 §2 末 |
| 4 | **视角与两个发射键都在右上角、同一只手** | `ViewPad` 按住拖动、松手回中，右手拇指一松视角就回正；它又要按发射键，无法一边保持侧视一边开火 | 真机 `vx/vy` 松手即 0；版面见 `YOKE.md` §三 |

另外两条不是按键逻辑、但同样卡对抗：手机靠**倾斜**控杆，大过载盘旋时手会跟着甩
（`YOKE.md` §九「绝对位置映射」）；`S8` 是单向循环，「武器 ↑/↓」不能像菜单上下翻（§2）。

### 9.3 要真能打，按优先级补三件事

| 优先级 | 改什么 | 代价 / 权衡 |
|---|---|---|
| P0 | 发射键门槛降到 ~120ms，或加「对抗模式」开关（安全 250ms / 格斗 120ms） | 误触保护变弱：划过一般 <60ms，120ms 仍能滤掉，但不再是「几乎不可能误碰」 |
| P0 | 启用 7–9 预留位：`S1_Forward` 进 DGFT、`S1_Press` 退出、`S2_Press` 解锁目标、`S2_*` 切子模式 | 要改 `YokeBtn`、重排战斗页按钮、各机型重绑；你之前说过预留位先别绑，需确认 |
| P1 | 机炮选择 / FEED 走 iPad 的 SMS 页，或新增两条固定命令 | 依赖 MFD 页面识别可靠性，见 `docs/JF17-MFD.md` |

**这三项都还没动代码** —— 分别动的是误触安全策略、按钮集合、以及你刚定下来的版面，
属于要你拍板的取舍。说一声要哪几项，我照着改并重新装机验证。

> 绑定方式本身没有疑义：这些全都走 **vJoy `JOY_BTNx` 按钮**，不是轴，也不是
> `docs/JF17-CONTROLS.md` 里那套 `/cmd` 座舱 clickable 命令 —— 后者是给 iPad 点座舱
> 开关用的（设备号 + 命令号），拿它当发射键会毫无反应。
