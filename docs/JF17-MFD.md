# JF-17 MFD 操作说明（来自飞行手册）

> 来源：`DCS World/Mods/aircraft/JF-17/Doc/DCS JF-17 Flight Manual CN.pdf`
> 关键页：p56（键位布局）、p62（周边键语义）、p57（显示内容）、p242（雷达控制菜单）
>
> **为什么单独成文**：MFD 的键是「多义键」——同一个物理键在不同画面上功能完全不同。
> 这和我们之前做的襟翼、起落架那类「一键一义」的开关是两回事，不能用同一套思路处理。

---

## 一、每块 MFD 的键位（p56）

```
        U1  U2  U3  U4  U5
  ┌────┬─────────────────┬────┐
  │SYM │                 │ PWR│
L1│    │                 │    │R1
L2│    │      屏幕        │    │R2
..│    │                 │    │..
L8│    │                 │    │R8
  │CONT│                 │BRT │
  └────┴─────────────────┴────┘
        D1  D2  D3  D4  D5
```

- **四个角**：`SYM` 符号亮度 / `PWR` 电源 / `CONT` 对比度 / `BRT` 亮度
- **上方 U1–U5**（5 个）
- **下方 D1–D5**（5 个）
- **左侧 L1–L8**（8 个）
- **右侧 R1–R8**（8 个）

合计 26 个周边键 + 4 个角键 = **30 个**。

---

## 二、哪些键是「固定的」（p62）

大部分键的功能**随画面变化**，但有几个是固定的：

| 键 | 功能 |
|---|---|
| **D3** | 选择**上部区域主菜单（MENU）** |
| **R8** | 选择**下部区域小画面菜单** |
| **U1** | 通常显示当前画面名称 |
| **D1** | 数字输入时旁边显示 `CLR`（清空） |

### 快速切换键（D2 / D4）

**D2**（每块屏各不同）：

| 屏 | D2 切到 |
|---|---|
| 左显 | 战斗（CMBT） |
| 中显 | **雷达** |
| 右显 | 水平状态显示器（HSD） |

**D4**：

| 屏 | D4 切到 |
|---|---|
| 左显 | 外挂管理（SMS） |
| 中显 | 无 |
| 右显 | **数据链信息（CLINK）** |

> 你说的「现在在 clink」= 右 MFD 的数据链页。**按 D3 回上半区菜单**，或按 D2 切到 HSD。

## 三、雷达相关的键（p242）

> 在 MFD 的雷达界面上可以通过点击 **U5** 按键进入**雷达控制菜单**。

雷达模式（RWS / TWS / VS / SAM）的切换在雷达画面里，具体是哪个键要看画面上的标签——
**我们读不到 MFD 画面内容，所以只能试**。

## 四、代码侧：element ID 与布局的关系（未知）

| MFD | element ID 范围 | 数量 |
|---|---|---|
| 左 | 734 – 766 | 33 |
| 中 | 767 – 799 | 33 |
| 右 | 800 – 832 | 33 |

每个 MFD 的 33 个控件里，**32 个是 `default_push_button`，1 个是 `default_2_position_tumb`**：

- 左：`741`
- 中：`774`
- 右：`807`

那个 toggle 很可能是 **PWR 电源**（它在定义顺序里排第 8，混在一堆按钮中间）。

**ID 是连续的，但连续 ≠ 按位置排列。** 我试图用「U1-U5, D1-D5, L1-L8, R1-R8」的顺序去猜，但 741 是 toggle 打断了这个假设，
所以**无法从代码推断映射，只能一条一条试**。

## 五、怎么试（下次进任务时做）

1. 把中 MFD 切到**雷达页**（手动用鼠标点 D2，或者试 `740`）
2. 我一次发一个键，你看画面变化
3. 记下「哪个 ID → 哪个功能」

**优先试这几个**（按价值排）：

| 目标 | 候选 ID | 说明 |
|---|---|---|
| **D3（回菜单）** | 需试 | 万能回退键，按错了也能回来 |
| **D2（中显切雷达）** | 740 | 验证键位顺序的第一步 |
| U5（雷达控制菜单） | 738 | 进入雷达模式切换的入口 |

**为什么先试 D3**：它是「撤销键」——万一试错切到了乱七八糟的页面，按 D3 就能回菜单。
先把退路打通，再试别的。
