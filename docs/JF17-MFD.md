## 一、每块 MFD 的键位（手册 p56）

```
        U1  U2  U3  U4  U5
  ┌────┬─────────────────┬────┐
  │SYM │                 │ PWR│
L1│    │                 │    │R1
L2│    │      屏幕        │    │R2
..│    │                 │    │..
L8│    │                 │    │R8
  │CONT│                 │BRT │
  └────┴─────────────────┴────┘
        D1  D2  D3  D4  D5
```

- **四个角**：`SYM` 符号亮度 / `PWR` 电源 / `CONT` 对比度 / `BRT` 亮度
- **上方 U1–U5**、**下方 D1–D5**、**左侧 L1–L8**、**右侧 R1–R8**
- 每块屏 **33 个**可控件：U5 + D5 + L8 + R8 + Power + SYM± + CONT± + BRT±

## 二、哪些键是「固定的」（手册 p62）

大部分键的功能**随画面变化**，但有几个是固定的：

| 键 | 功能 |
|---|---|
| **D3** | 选择**上部区域主菜单（MENU）** —— 万能撤销键 |
| **R8** | 选择**下部区域小画面菜单** |
| **U1** | 通常显示当前画面名称 |
| **D1** | 数字输入时旁边显示 `CLR`（清空） |

### 快速切换键（D2 / D4）

**D2**：

| 屏 | D2 切到 |
|---|---|
| 左显 | 战斗（CMBT） |
| 中显 | **雷达** |
| 右显 | 水平状态显示器（HSD） |

**D4**：

| 屏 | D4 切到 |
|---|---|
| 左显 | 外挂管理（SMS） |
| 中显 | 无 |
| 右显 | **数据链信息（CLINK）** |

> 「现在在 clink」= 右 MFD 的数据链页。**按 D3 回上半区菜单**，或按 D2 切到 HSD。

规律（省得背表）：
- 三块屏的基准 ID 是 734 / 767 / 800，每屏 33 个。
- `U_i = base+2+(i-1)`、`L_i = base+8+(i-1)`、`R_i = base+16+(i-1)`。
- `D_i`：左屏是 `base+26+(i-1)`，中/右屏是 `base+24+(i-1)` —— **只有这一处不一样**，
  因为左屏的 `Cont ±` 排在 D 前面（758/759），中右排在 D 后面。
- `Power = base+7`、`Sym+ = base`、`Sym- = base+1`、`Brt+ = base+31`、`Brt- = base+32`。

## 四、设备号与命令号（发给 /cmd 的东西）

**设备号 `dev = 47`**：`devices.lua` 用 `counter()` 一个个发号，MFCD 是第 47 个
（1 ELECTRIC_SYSTEM … 32 GEAR … 35 FCS … 46 UFCP、47 MFCD、48 HMD）。
三块屏共用一个 `MFCD` 设备，靠命令号区分屏。

**命令号 = 元素 ID + 2502**。推导在 `command_defs.lua` 第 428–433 行：

```lua
start_command = 3001
deka_counter  = start_command
for i=500,999 do click_cmds['PNT_'..i] = dcounter() end
-- local function dcounter() deka_counter = deka_counter + 1; return deka_counter end
```

`dcounter` 是**先加后返回**，所以 `PNT_500 = 3002`、`PNT_N = N + 2502`。
和早前实测的「PNT_505 → 3007」对得上。

**值 `val`**：
| 类型 | val | 例子 |
|---|---|---|
| `default_push_button`（33 个里的 32 个） | `1` | U1、D3、L1… 发 1 即一次按下 |
| `default_2_position_tumb`（只有 Power） | `1` 开 / `-1` 关 | `arg_value = {1,-1}`，见 `clickable_defs.lua` |

`Sym ± / Cont ± / Brt ±` 是**独立的两颗按钮**（不是旋钮），按一次走一档。

## 五、iPad 上怎么用（panel.html 已实现）

`http://<PC 局域网 IP>:8080/panel` 顶部多了 **「MFD」** 标签页：

- 三块屏切换（左 / 中 / 右），键位按真实布局摆：上 U1–U5、左 L1–L8、右 R1–R8、下 D1–D5。
- 屏幕中央显示**最后按了哪个键**，下面一行是 Export.lua 的回执：
  - `已执行 · 47:3295:D` —— 设备拿到、方法调用了
  - `没执行 · 47:3295:N` —— `GetDevice(47)` 返回空
  - `没执行 · 47:3295:M` —— 设备有但没有 `performClickableAction`
- **D3 带暗金色边框**，它是撤销键，认不出画面时按它。
- 亮度/对比/符号的 ± 和电源在下面一行。**电源要长按 0.6 秒**（两档开关，按错画面就黑了）。

点一下发一条 `POST /cmd {"dev":47,"cmd":<ID+2502>,"val":1}`，链路和起落架那些按钮完全一样。
改 `panel.html` 只需刷新浏览器；**Export.lua 没动**，这次不用重启任务。

## 六、还没确认的：键在**各画面上**是什么功能

现在能确定「哪个 ID 是哪个物理键」，但确定不了「雷达页上的 U3 是 RWS 还是 TWS」——
那取决于画面画了什么，而 **MFD 的画面内容 DCS 不导出**（`LoGet*` 里没有任何 MFD 相关接口，
`LockedTargetInformation` 一律 nil）。要读到画面只能上 DCS-BIOS 或抓 indication 纹理。

所以现在的状态是：
- ✅ 键能按、按的确实是那颗键 —— 已由代码确证
- ❓ 按下去会发生什么 —— 只能人看着屏幕记

**记功能的办法**（比之前的盲试省事得多）：

1. 中 MFD 按 `D2`（792 / 3294）切到雷达页。
2. 屏幕上看 U1 显示的画面名，确认真的在雷达页。
3. 从上往下按 `U1…U5`，每按一个记下屏幕变化；再按 `R1…R8`、`L1…L8`。
4. 按错了按 `D3`（793 / 3295）回菜单。

按完把「画面 + 键 + 结果」记进本文件的第七节，就永久有了。
