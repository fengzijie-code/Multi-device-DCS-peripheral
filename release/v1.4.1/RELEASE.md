## 这一版有什么

### 1. 油门：默认反转 + 显示层修正（实飞报 bug）

- **默认反转**：DCS 油门轴方向相反，iPad 发 `1 − 手指位置` 去补。
  `invT` 默认值 `false → true`（校准页开关仍可手动关）。
- **反转不碰显示层**：以前把反转完的值直接拿去画旋钮/油门条/百分比，
  反转一开手往上推、屏上油门反而往下走。现在显示永远跟着手走
  （上推 = 加油门），反转只作用在发往 beacon 的 `st.t` 上。

### 2. 杆盘：纯体感，无触摸（用户需求）

- 盘面**不再吃任何触摸**：杆量只来自陀螺仪。油门 / 脚舵 / 按钮仍是触摸
  —— 只有杆这条轴是体感专属。
- 杆量读数（`0.00 / 0.00`）与「杆量 · 触点浮动」标签撤掉，触摸环整个删除；
  **绿点 = 体感杆位指示器**，贴到内圈（`.lim`）= 满杆，体感关闭即隐藏。
- 配平（force trim）照旧可用，语义变为「把当前体感输出记成偏移」。

### 3. 网线直连全套（当天从零打通）

用一根网线把 iPad 和电脑直连（无 DHCP、无路由器），三条坑全填了：

| 坑 | 现象 | 解法 |
|---|---|---|
| 无 DHCP，两端 APIPA | iOS 对 `169.254.x.x` 不可靠，显示「无网络」 | `tools/set-static-ip.bat` 一键固定 PC 侧 `192.168.77.1/24`；iPad 手动 `192.168.77.2` |
| iOS 把「无互联网」网卡标离线 | ping 全通，Safari **一个包都不发** | `tools/captive.py` 喂饱联网探测：DNS :53 按询问者网段答本机，HTTP :80 对 iOS/Win/Chrome 探测各答各的正文（`Success` / 204） |
| 新 IP 不在证书里 | Safari 报「不是私密连接」 | `start-ipad.bat` 启动时自动枚举网卡 IP、自动重签 leaf 证书（根 CA 不变，iPad 不用重装描述文件） |

配套改动：`open-firewall.bat` 增加放行 **80/TCP + 53/UDP**（captive 探测要用）；
`run-all.py` 在 iPad 模式自动带上 captive 子进程（`--no-captive` 可关，端口被占不挡启动）。

### 4. 链路数据（实测，网线直连）

- 服务端 keep-alive HTTPS POST 往返 **0.35ms**（PC 侧基准）
- iPad 操纵帧 48Hz 稳定流入、零丢帧；页面显示 ~22ms 为 iOS Safari fetch 的
  平台级固定开销，与链路无关，恒定无抖动

## 有线直连怎么配（一次性）

1. 电脑：双击 `tools\set-static-ip.bat`（自动弹 UAC）—— 固定 `192.168.77.1/24`
2. iPad：设置 → 以太网 → 配置 IP **手动** `192.168.77.2 / 255.255.255.0`，路由器 `192.168.77.1`
3. iPad：配置 DNS **手动** `192.168.77.1`（探测应答器在这一步才喂得到 iOS）
4. 电脑：`tools\open-firewall.bat` 右键管理员跑一次（放行 80/53/8080/8443）
5. 双击 `tools\start-ipad.bat`，iPad 打开 `https://192.168.77.1:8443/yoke`

以后每次飞行：**插网线 → 双击 `start-ipad.bat` → iPad 开页面 → 解锁**。
