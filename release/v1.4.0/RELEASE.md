## 这一版有什么

### 1. iPad 输入端 `/yoke` 重做

四页（照 Pixel 端）：**仪表 / 起降 / 战斗 / 校准**。

| 页 | 内容 |
|---|---|
| 仪表 | 460px 姿态球 + 10 个数字框（IAS/ALT/VS/AGL/HDG/G/MACH/AOA/RPM/FUEL） |
| 起降 | 襟翼收/放、起落架、减速板开/收、轮刹 |
| 战斗 | 机炮、投放、武器切换、干扰弹、雷达锁定、TDC 四向 |
| 校准 | 死区 / 行程 / expo + 体感校零 |

**换页时杆盘不挪位**：`#colL` 定宽，起降和战斗两套面板在它内部互相顶替。
让内容自己撑开的话，推着杆切页时杆心会跳一下、杆量跟着甩。

### 2. 美术：玻璃 HUD，不是仪表盘

不画面板 —— 没有卡片底色、没有边框盒子、没有实心顶栏，只有 1px 细描边、圆、
小字距的浅色字。底图是 DCS 座舱，任何实心色块都会立刻变成"网页控件贴在上面"。

状态色固定语义：青 = 已连接/已解锁，洋红 = 上锁/油量细线，蓝 = 右舵，
琥珀 = 未接管/左舵，红 = 开火/投放。

### 3. 位置按"手位"排，不按"好看"排

| 位置 | 控件 | 为什么 |
|---|---|---|
| 中偏左 | 杆盘（触点浮动 + 位置亮点，24 道刻度环） | 左右手都能推 |
| 左·竖条 | 油门（圆徽章骑在条上，松手保持） | 左手大拇指 |
| 右下角 | 脚舵（横向比例条，松手回中） | 右手管杆盘 + 按键 + 脚舵，和真机一致 |
| 左下角 | **解锁 / 已解锁（100px 大圆）** | 见下 |
| 顶部 | 从 `y=38px` 起 | iPad 主屏模式下状态栏（时间/电量）会盖住页面顶边 |

解锁键原来只是顶上一颗 11.5px 的 chip —— 实飞时右手在杆上、左手在油门条上，
没有一个指头会跑到左上角去点那么小的东西。现在它是左下角 100px 的圆：
大字是**动作**（解锁 / 已解锁），小字是**状态**（不发 / 正在发操纵量）。

### 4. 一键启动带预检

`tools/start.py`（中文提示全在这里，`.bat` 只负责找 python 并转发参数）。
起服务之前先查四件事 —— 它们失败时在 iPad 上表现**一模一样**：

| 查什么 | 不查会怎样 |
|---|---|
| 证书在不在、剩几天 | Safari 报"不是私密连接" |
| 证书 SAN 里有没有**当前这个 IP** | 换热点/换网线后必炸（重签只动 leaf） |
| 8080 / 8443 / 5011 是否被上次的窗口占着 | 服务起不来，页面打不开 |
| 防火墙规则 `DCS Peripheral Bridge` | iPad 连不上，八成就卡在这 |

服务起来后去问自己的 `/info`，把**真实在听**的 IP 印成可点的地址，再自检
`http 200 · https 200`。

## 修了什么（都是实飞才暴露的）

| 问题 | 根因 | 修法 |
|---|---|---|
| iPad 上"已丢失网络连接" | 证书有效期 3650 天，iOS 硬上限 398 天，握手层直接断 | 改成 365 天；每次启动查到期 + SAN |
| 8443 突然打不开，之前还能开 | TLS 握手做在主线程 `accept()` 里，一条哑连接就能堵死整个端口 | 握手挪到每连接线程 |
| 端口显示"空闲"但服务起不来 | Windows 的 `SO_REUSEADDR` 和 Unix 语义相反：端口被占时 `bind` 照样成功 | 改判 `netstat` 的 LISTENING 行 |
| 改了 `--vjoy-port` 杆就不动 | `mock` 的 `--target`、`beacon` 的 `--input-out` 没跟着端口走，两边日志都"正常" | 两个参数都从端口派生 |
| `start-usb.bat` 打一堆 Wi-Fi 地址 | beacon 横幅不分模式 | 加 `--usb`，只印 `127.0.0.1` 那一条 |
| 脚舵数值飘在半空 | 盒子高度改小后 `top/bottom` 定位失效 | 改成贴着滑轨算 |
| 战斗页 TDC 撞脚舵 | 右列居中排，最低到 675，脚舵从 702 起 | 右列改从顶部起排，按钮 72→68 |

## 验收

`tools/check-yoke.py`（playwright + 系统 Chrome，1194×834 iPad 横屏视口，
用 CDP 真的发触摸事件，https 下还假造陀螺仪倾斜，然后回头查 `/input` 收到了什么）：

```
python tools\start.py --port 18080 --udp-in 15010 --tls-port 18443 --vjoy-port 15011 --no-vjoy mock
python tools\check-yoke.py https://127.0.0.1:18443/yoke      # 74 项
python tools\check-yoke.py http://<本机IP>:18080/yoke         # 70 项（必须用局域网 IP）
```

**74 / 70 项全过。**

## 已知限制

- 只做**横屏**（竖排明确不做）。
- 体感必须走 HTTPS，且要装一次根 CA —— iOS 不给明文页面的传感器数据。
- 同时按下的点数受 iPad 触摸屏上限约束：推杆 + 油门 + 脚舵 + 按钮一起用时，
  已经贴着上限在跑。
- Android 端自 v1.3.7 未动，两个端可以混着跑（`/input` 是同一个入口）。
