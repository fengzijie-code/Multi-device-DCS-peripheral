① 简易座舱 · 点一下，飞机就有反应

这是一台不用进游戏就能操作的简易座舱：拨动开关会动、三块 MFD 与 HUD/UFCP 会亮、告警灯与发动机状态会跟着变。每点一下，右侧「操作效果」都会写清你做了什么 → 系统有什么反应 → 出自手册哪一页。默认冷舱全关，按「一键演示」可看完整开车过程。

纯前端状态机 · 不连接 DCS · 不发 /cmd
这台模拟座舱怎么读（外观、状态来源、能模拟到哪一步）
  • 外观：小滑块 = 两档 / 三档开关（绿=接通、琥珀=中间档），圆盘 = 旋钮，圆按钮 = 按压键，三角 = HOTAS 多向帽，斜纹条 = 手柄 / 保险盖，圆点 = 只读指示灯。鼠标悬停看得到面板、手册页码与要点。
  • 屏幕：三块 MFD 的 U/D/L/R 周边键可点；D3 回主菜单、D2/D4 切页、R8 下半区、U5 雷达控制菜单（§1.8.3 p48、docs/JF17-MFD.md）。屏幕内容由当前电源 / 航电 / 主模式状态推导，不是贴图。
  • 联动：三个电源开关全接通才有电；CMBT 起航电；RDR 自检后进 STBY；惯导 FAST → 输 THDG → NAV；ENG CTRL + STARTER + 油门 + GND 才让 N2 爬到 70%；没开主军械就扣扳机会明确提示「条件不满足」。
  • 文字描述：右侧「操作效果」逐条给出操作、系统反应、手册依据与手册要点；点日志条目可展开完整说明；「当前飞机状态」是同一套状态的表格视图。
  • 边界：这是教学用状态机，不复现真实航电逻辑、不输出 DCS 指令；数值（N2、气压等）取手册典型值做示意。

    模拟与真实座舱的三个差别
    • 面板按「方位 → 控制盒」分组，不按真实几何比例，开关位置以座舱内视图为准。
    • 档位循环是简化的：真实三档 / 十二档旋钮这里只走几个代表性位置。
    • 告警与画面是规则推导的示意，不是 DCS 实时回传；真实显示以游戏与手册为准。

    三种难度，按上手顺序走

    1. 认位置：按键上写全「英文缩写 + 中文名」，边找边认。
    2. 只给缩写：座舱里丝印就是英文，练到看见 A/B、EMG HYD 就知道在哪。
    3. 盲操：按键文字全部隐藏，靠肌肉记忆点位置；鼠标悬停可临时查看，考场模式下别悬停。

    建议路线：先只勾「前仪表台 + 右控制台」跑一遍冷舱上电，再把「左控制台 / 左后 / 右后」加进来，最后切盲操。

    按钮右上角的小标记是什么意思
    • SW 两档 / 三档开关　KN 旋钮　BT 按钮
    • HT 多向帽（HOTAS 上的四向开关）　LV 手柄 / 保险盖
    • SK 虚线框 = MFD/UFCP 画面软键，不是实体开关，功能随页面变（§1.8.3 p48）
    • IND 只读指示灯 / 信号旗，不是按键，但快速上手必须认识它在哪

      为什么要按顺序练

      JF-17 冷舱开车不是「把开关全打开」，而是有依赖：先上电 → AAP 启航电 → 惯导对准（期间别动飞机）→ DTC 加载 → 才轮到发动机。找键训练练的是「在哪」，流程训练练的是「什么时候」。

      已被手册明确写死的前置条件
      • SHARS / INS 对准期间移动飞机会导致对准异常（§2.3.3 p139、§2.3.4 p143）
      • 机炮要先选 GUN、首次或卡弹后点 FEED 充弹；FEED 点超过 3 次不再响应（§4.3.1 p205–206）
      • AAP 的 OFF 要按住 2 秒以上，且条件是「启动航电后上过天又回到地面」（§1.11 p61）
      • 关车前慢车至少停留 1 分钟冷却发动机（§1.2.3 p32）

      手册只写「看向左控制台的发动机控制面板」而没有逐个列按钮时，控件名以 控件表 补，并在速查里标来源；手册没写的方位关系不臆造，只在总览的「方位原文」里列有出处的六条。

      第 9 / 10 章：不是按键，但考场上要用 —— 速记卡

      着陆与减速（§2.7.1 p171 / p176）

      • 约 135 kt 放减速伞，约 20 kt 抛伞
      • 最大刹车速度 145 kt；刹车柔和逐渐加力
      • 4 号挂点挂副油箱 / GBU-10 时迎角 < 10°，不挂时 < 12°
      • 口径差异：§1.7.3 p44 用 km/h（放伞 ≤300，应急 ≤340；20～30 km/h 抛伞），§2.7.1 p171 用 kt（约 135 kt 放、低于 20 kt 抛）。两处都是手册原文，别混算。

      起飞与加力（§1.2.3 p32）

      • 挂副油箱通常用加力；挂弹 + 副油箱或炸弹必须加力
      • 先松刹车再推油门接通加力
      • 关车前慢车冷却 ≥ 1 分钟

      发动机 / 对准（§2.3.13 p156、§2.3.4 p143）

      • 慢车 N2 ≈ 70%，T4 < 500 °C
      • N2 > 60% 时 HYD LOW 告警灯灭
      • SHARS / INS 对准期间不要移动飞机

      ⑦ 用法、边界与来源

      怎么用（最短路径）

      1. 简易座舱（①）：不进游戏也能拨开关。点「一键演示」看完整冷舱开车，或选一条引导检查单按提示点；右侧会写清「做了什么 → 有什么反应 → 手册依据」。
      2. 找键训练（③）：选范围 → 开始 → 看题 → 在虚拟座舱点控件。答完自动下一题，H 提示、S 跳过、Enter 下一题。
      3. 流程训练（④）：选一条流程 → 从头开始 → 按步骤顺序点。适合第一次进座舱前把冷舱开车过一遍。
      4. 控件速查（⑤）：忘了某个缩写是什么意思，点名字看浮层；按方位筛选能当 checklist 用。
      5. 覆盖核对（⑥）：想确认「手册哪一章练到了」就看这里，也写明了哪些章节不设按键。

      进度（对错次数、错题本、连击、偏好）存在浏览器 localStorage，键名前缀 jf17trainer.v1，不会动项目里其他页面的数据。刷新不丢，「清空记录」才清。

      快捷键
      • H 提示：第一次只给方位，第二次高亮正确按钮；用了提示连击归零
      • S 跳过：算一次答错，进错题本
      • Enter 下一题　P 暂停 / 继续
      • 切换顶部标签页不会中断计时（除非按暂停）

      边界：这是训练器，不是座舱控制器

      • 不连接 DCS：点这里的按钮只在页面内判分，不会发 /cmd、不会碰 vJoy、不会动真实座舱。
      • ① 简易座舱也是纯前端：屏幕、指示灯、发动机数值由本机状态机推导，是教学示意，不是 DCS 实时回传；N2 等数值取手册典型值。
      • 布局是示意：按「方位 → 控制盒」分组，不按真实几何比例；真实开关位置以座舱内视图与手册插图为准。
      • 档位题考的是「这个开关在哪」，不是替你记住所有档位；目标档位写在题面和反馈里，实际飞行按手册 checklist。
      • MFD 软键功能随画面变（§1.8.3 p48），训练只考固定键位与所属屏幕。
