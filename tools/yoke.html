手感与校准

改动立刻生效并保存在这台 iPad 上。默认值取自 Pixel 端实飞调出来的那一组。

1体感行程

死区吃掉手持微抖；满行程是「倾斜多少度算满杆」，越小越灵敏也越累； 曲线 0 = 线性，越大中位越细、末端越陡。只影响体感，杆盘始终线性。

2方向与开关

右边写着「开」就表示这条轴被反向。油门默认就是开的（DCS 油门轴方向相反， iPad 这头负责补回来）；屏上的油门条永远跟着手走，不受这里影响。配平按钮只在飞直升机时有用 （把当前杆位锁住、松手不回中）；飞固定翼可以关掉，顶栏会少两个按钮。

体感需要 HTTPS

iOS 从 13 起只把陀螺仪数据交给安全上下文 —— 也就是 https 或本机回环。 普通 http 下，方向事件会被系统直接掐掉，按钮按了当然没反应。

!PC 那边还没开 HTTPS

证书文件已经生成好了（tools/certs/），缺的只是启动参数。关掉这个窗口， 在 PC 上重新双击 tools\start-ipad.bat —— 它发现证书就会自动开 8443。 如果启动日志里出现 [x] HTTPS :8443 起不来，把那行报错发我。

1先装一次根证书

不装也能用（下一步可以绕过警告），但每次都要手点一遍，而且加不了主屏图标。 就从这个页面点，不用 AirDrop、不用发邮件：

下载根证书
  1. Safari 问「此网站正尝试下载一个配置描述文件」→ 允许
  2. 设置 → 通用 → VPN 与设备管理 → 已下载的描述文件 → 安装 （提示「未签名」是正常的，继续装）
  3. 设置 → 通用 → 关于本机 → 拉到最底 证书信任设置 → 打开 DCS Peripheral Local CA 的开关

第 3 步最容易漏：只安装、不开信任开关，证书还是「不受信任」，下一步照样报警告。 装完回来刷新这个页面；如果仍然提示不安全，就是这一条没做。

2打开这条地址

打开 https 版
地址栏里必须带 https:// —— 只写 IP 和端口，Safari 会当成 http 发， 而这个端口讲的是 TLS，表现就是「打不开网页 / 已丢失网络连接」。
同一台 iPad、同一个网络。如果还提示「不是私密连接」： 点 显示详细信息 → 访问此网站 就能进去。 别点「取消」 —— 取消会退回上一个页面，也就是 http 那版，看着就像被跳回去了。

3添加到主屏幕（建议）

在 https 页面上点分享 → 添加到主屏幕 → 以后从桌面图标打开，没有地址栏也没有工具栏。 主屏图标只会指向你添加时那个地址，所以一定要在第 2 步的 https 页面上添加； 在 http 页面上添加，图标以后永远打开 http。

这也是非要装证书的原因：自签证书在普通标签页里还能点「继续访问」， 但主屏窗口没有那个按钮，只会白屏。
