体感需要 HTTPS

iOS 从 13 起只把陀螺仪数据交给安全上下文 —— 也就是 https 或本机回环。 普通 http 下，方向事件会被系统直接掐掉，按钮按了当然没反应。
你现在打开的是 —。

!PC 那边还没开 HTTPS

证书文件已经生成好了（tools/certs/），缺的只是启动参数。关掉这个窗口， 在 PC 上重新双击 tools\start-ipad.bat —— 它发现证书就会自动开 8443。 如果启动日志里出现 [x] HTTPS :8443 起不来，把那行报错发我。

1换成这条地址

打开 https 版
同一台 iPad、同一个网络。IP 是 PC 的地址，端口就是 HTTPS 那个。 若提示「不是私密连接」，先做完第 2 步再来点它。

2装一次根证书（约 1 分钟）

不用 AirDrop、不用发邮件，就在这个页面上点：

下载根证书
  1. Safari 问「此网站正尝试下载一个配置描述文件」→ 允许
  2. 设置 → 通用 → VPN 与设备管理 → 已下载的描述文件 → 安装 （提示「未签名」是正常的，继续装）
  3. 设置 → 通用 → 关于本机 → 拉到最底 证书信任设置 → 打开 DCS Peripheral Local CA 的开关
  4. 回 Safari 打开第 1 步那条 https 地址，地址栏不再报警告

3添加到主屏幕（建议）

在 https 页面上点分享 → 添加到主屏幕 → 以后从桌面图标打开，没有地址栏也没有工具栏。 这也是非要装证书的原因：自签证书在普通标签页里还能点「继续访问」， 但主屏窗口没有那个按钮，只会白屏。

想先试体感、暂时不装证书也行：打开 https 地址时提示「不是私密连接」， 点 显示详细信息 → 访问此网站 就能拿到传感器数据 —— 只是每次都要点一遍，且不能加到主屏。
